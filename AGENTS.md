# CareerGround evidence rules

These rules apply to every contributor and automation in this repository.

- Capture a reproducible baseline before a bug fix or performance change.
- Verify before and after under the same data, runtime, viewport, and command.
- Never invent metrics. Write `정량 측정 불가` when the evidence does not support a number.
- Never capture personal data, tokens, production data, private source code, uploaded source material, or internal URLs.
- UI changes require deterministic evidence at 1440×900 and 375×812.
- Every behavior change needs a regression test.
- Troubleshooting documents may only claim facts present in their evidence manifest.
- Public blog drafts must redact repository-internal identifiers and all user-supplied content.
