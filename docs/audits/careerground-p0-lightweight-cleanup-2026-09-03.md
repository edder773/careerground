# CareerGround P0 경량화 결과

## 범위

현재 공개 기능인 채용공고, 코딩테스트, 자격증 외부 링크, 브라우저 로컬 즐겨찾기에 필요하지 않은 프런트엔드 자산과 개발 경로를 제거했다. 운영 D1의 과거 테이블과 채용공고 자동화는 이번 P0 범위에서 변경하지 않았다.

- 삭제: 학습 정적 자산 125개, 학습 카탈로그 생성·이미지 처리 도구와 원본 JSON
- 삭제: 사용되지 않는 `config`, `testing`, `ui` workspace와 고립된 Myers diff 구현·테스트
- 삭제: Tailwind 빌드 플러그인, 미사용 dropdown·`clsx` 의존성
- 정리: 현재 TSX에서 사용하는 선택자와 상태 선택자만 남기고 레거시 CSS 제거
- 보강: 채용 달력·목록·필터뿐 아니라 코딩테스트·즐겨찾기의 1440×900, 375×812 시각 증거 추가

## 회귀 방지

정리 전후 8개 기준 스크린샷의 SHA-256을 비교했다. 달력, 일정 모달, 목록 필터, 코딩테스트, 즐겨찾기의 데스크톱·모바일 결과가 모두 byte-for-byte 동일했다. 다중 브라우저가 같은 증거 파일을 동시에 덮어쓰지 않도록 Chromium 프로젝트만 기준 스크린샷을 기록하게 했다. Firefox, WebKit, 모바일 Chromium은 동작·접근성 검증을 계속 수행한다.

검증 명령과 최종 결과는 이 변경의 pull request 본문에도 기록한다.
